# Security policy

Nitrate is a personal, non-commercial fork of [Prismedia](https://github.com/pauljoda/Prismedia) and has no
supported releases. If you find a vulnerability in code that Nitrate added (the reader, annotations,
lookup, search or Windows scripts), report it privately through this repository's
[private vulnerability reporting](../../security/advisories/new) form, and do not post details in a public issue.

For vulnerabilities in Prismedia's own code, report them to the upstream project through its
[security policy](https://github.com/pauljoda/Prismedia/security/policy).
